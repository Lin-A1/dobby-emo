会看，

一个会看、会停、会反应的 AI 助手形态。眼神先变，姿态随后跟上，角色本身始终是同一只 Dobby。

13 种情绪状态 静置也不漂移 可嵌入 AI 应用

表达，不靠换脸

眼神矢量眼环负责视线、眨眼和情绪形状，切换连续。
轮廓开心会抬头，害羞会侧过去，难过会沉下去。
节奏静止优先，只有切换状态时做一次明确过渡。
接入一段 JSON 驱动状态，未知表情自动回待机。
交互靠近、抚摸、连戳、打字与滚动都能触发反应。
运行纯原生 JS + CSS，无框架、无构建，移动端可用。

接到你的 AI 里

引入引擎，每轮回复附带一段 JSON 即可驱动表情。

<div id="dobby-layer"></div>
<script src="dobby.js"></script>
<script>
  const dobby = new DobbyEmo(
    document.getElementById('dobby-layer')
  );

  dobby.handleAIMessage(
    '{"emotionId": "30", "tips": "正在思考用户问题…"}'
  );
</script>

未知 emotionId 或 JSON 解析失败会自动回落待机，并触发 onError。
